## Cara Menambahkan Repositori

1. Buka aplikasi Anikku, Aniyomi, atau Dantotsu.
2. Masuk ke menu Settings > Browse > Extension repositories > Add Repo.
3. Masukkan URL berikut:
   ```text
   https://raw.githubusercontent.com/wdinrev/dou-repo/main/index.min.json
   ```
